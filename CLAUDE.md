The goal of this repository, is to provide reference calculations for risk reporting in the context of Insurance linked securities and reinsurance. 

The idea, is to keep the specs language agnostic, so that they can be checked across different languages.

/conformance    # Schema, data and definitions of test cases
/docs           # doc website for publication
/impl           # lanugage specific implementations
/spec           # Repository Spec
/tools          # Utilites for things like generating test data
